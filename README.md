Auditoría de seguridad tipo Black Box realizada sobre infraestructura web corporativa, enfocada en servidores IIS, aplicaciones ASP.NET y servicios de correo.
El objetivo es identificar riesgos de seguridad, exposición de superficie de ataque y debilidades estructurales, aplicando metodología de Ethical Hacking y enfoque Red Team.
Incluye análisis de arquitectura, hallazgos críticos, matriz de riesgo CVSS y recomendaciones de mitigación sin impacto operativo.
